## 原因与改动

轮播按需初始化队伍。原 `PartyCarousel.changeIndex` 在目标容器未初始化时，就将其角色格子注册给触摸处理器，并使用尚未准备好的队伍资料更新名称。随后 `update` 初始化容器，并不能补回此前复制到触摸映射中的空值。

`patch_swf.py` 只向主 ABC 288 的两个既有方法插入指令：

- `66523 changeIndex`：检查目标下标，先调用原有 `initialzeAt(newIndex)`，准备旧队伍名称资料，再执行原有的清理触摸状态、重绑格子、更新名称和选中队伍流程。旧下标越界时名称过渡使用目标队伍。
- `66013 beginTouch`：取不到角色格子时忽略本次触摸，避免直接调用空对象的 `get_touchable`。

保留 `66481 update` 的每帧仅更新当前队伍优化；未引入相邻队伍常驻更新。没有新增类、字段、方法签名或常量池内容。插入可逆，还原后的两个方法与输入完全一致。

此前云服日志存在 `beginTouch` 和 `PartyCarouselView.onSwitchParty` 两类切队空引用；切队相关六个类的 164 个方法与此前公网客户端一致。不能仅凭 F1009 错误码将商店等其他空引用归入本问题。
