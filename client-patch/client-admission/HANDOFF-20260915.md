## 已实现的服务端

源码 `src/lib/client-admission.ts`，HTTP 接入 `src/cn-server.ts`，TCP 接入 `src/multi/tcp/server.ts`。对应输出 `out/lib/client-admission.js`、`out/cn-server.js`、`out/multi/tcp/server.js`。

- 构建号 + HMAC 一次性挑战，账号绑定准入 token；HTTP 创号/登录/业务及 TCP 握手与后续消息均检查。
- 有效且绑定账号的 HTTP/TCP 活动自动将同一 token 延长 30 分钟；持续共斗无需普通 HTTP 触发续期，不因单纯达到固定 30 分钟掉线。
- 已绑定 token 到期后有 5 分钟仅限同账号身份验证续期的窗口；过期 token 仍禁止业务请求。未绑定无到期宽限。版本撤销、期限和密钥变更优先于宽限。
- 返回相对时间与恢复 action，支持未来客户端提前续期、重新握手、恢复登录、限流重试。进程重启导致未知 token 时返回握手恢复，不直接误报 APK 过旧。
- Android/iOS 独立 ID，各条目一个 platform（省略默认 Android），不能靠伪造 iOS 标记豁免。
- 配置/准入缓存为进程内状态，HTTP/TCP 须共享同进程；没有多节点共享状态方案。没有新增玩家表、持久化字段或修改存档格式。真实网络中断/服务重启仍可断线。

维护模板 `config/client-admission.json` 为 `enforce:false`、空 builds。不能把模板当作已准备好正式严格允许列表；更不能现在直接开云服严格模式而两端正式客户端尚未完成。

实际本地测试配对文件在忽略目录 `outputs/client-admission-private/`。`.gitignore` 有 `config/client-admission.keys.json` 排除规则。不要读取/打印/提交密钥内容；正式新号应另行配对，私有材料用独立受控伴随文件，不能混入公开包。APK 签名凭据按 AGENTS 中 DPAPI 规则，绝不交付到云服。
