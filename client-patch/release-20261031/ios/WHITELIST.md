- support/recipe-deps/pr43-ios/: only the eight actual-used Python files whose digest differs from current repository copies; original and candidate SHA-256 tracked separately.

Excluded: SDK/tool binaries, reconstructed game tree, ABC/SWF/AOT/IPA, native images, actual build reports, screenshots/chat, accepted registrations. Private reports used by guards are explicit hash-pinned external inputs. Generic matching tools remain repository dependencies and are not duplicated.

This source candidate has only PowerShell static inspection. It has not been imported, compiled, linked, packaged, or executed after relocation.
