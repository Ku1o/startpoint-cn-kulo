- r14 加入本机旧账号检测：没有新登录记录、尚未尝试且未完成迁移时，只读旧 `account` 和全局设备记录，发起一次 `/player-auth/local-claim-preview`。核验成功直接展示原角色/UID 与账号设置表单；缺失、损坏或不匹配时使用登录页或手动验证入口，已绑定存档提示账号登录。请求前保存尝试标记，断网/中断后不自动重发，可在「绑定旧存档 → 检测本机旧存档」手动重试；任一账号认证成功后保存完成标记。标记与多账号记录一起按服务地址保存。

- 2026-09-10 用户明确纠正：删除未备注账号只按账号备注判断，空备注或纯空白全部纳入，包括已绑定登录、设备绑定、管理端当前选中和无存档账号。先做完整数据库备份，再分批检查当前备注后删除；期间补上有效备注的账号保留。删除同时清除其登录凭据、验证码、存档及管理端选中引用，并断开对应联机连接。面板数量和提示使用同一范围。
