# 登录融合与 1.4.104 云服交付

本次将 r15 玩家登录方案融合到当前累计版本，连同存档导入导出修复和管理面板邮件排序提交。保留之前的深渊、称号、兑换、五重决战和九月角色资源，云服资源版本从 1.4.103 更新到 1.4.104。

## 服务行为

- 注册、账号密码登录、记住登录、切换账号、撤销凭据和双端连接认证按原方案保留。
- 旧存档可通过本机证据、旧 UID 与引继密码或管理员绑定码迁入登录账号；管理员重置码仍可用于恢复密码。按用户要求继续使用 HTTP 与明文玩家密码，不改变管理员认证或签名凭据。
- 管理面板包含账号登录状态、绑定/重置操作和未备注清理。未备注清理仍需管理员主动确认，按最终备注规则处理；部署不会自动清理账号。
- 五张五重决战场次/回执表登记目标侧保留策略，恢复导出和导入前备份；V1 覆盖同时保护房主、成员和受级联影响的队友记录。V2 可移植内容及原结构指纹保持兼容。
- 邮件页面依次为“发送邮件”“每日星导石自动邮件”“最近群发记录”。

## 部署边界

整合包从本次提交的明确运行文件及对应构建产物制作，兼容本会话已知的 1.4.103 普通、性能及 H400 修复版本。包括其后需要的服务代码、管理面板、游戏数据、CDN 清单与最终启用的 1.4.104 增量；不包含候选补丁、实验诊断客户端或个人测试数据。

保留服务器原 `.env`、数据库、原始 `.cdn`、依赖和日志。部署前停止服务并备份程序文件与持久化目录（包括 SQLite WAL/SHM，或使用一致性数据库备份），再从服务器项目根覆盖。依赖未变化，无需重新安装依赖；包内带对应 JS 和管理面板静态产物。按原方式重启后，登录模块自动创建所需表和索引，无需导入本地数据库或预设账号。

CDN 版本来自清单和启用补丁；只改旧 `CN_RES_VERSION` 环境变量不能完成更新。旧 1.4.103 玩家下载一个归并后的 1.4.104 增量即可。此次沿用此前已经生成的 iOS CDN 资源，没有重新执行平台完整性审计，也没有修改 IPA。

账号一旦绑定新登录机制，需要支持此机制的客户端才能登录；未绑定旧账号继续走兼容路径。现有累计登录 APK 是内网候选，APK/IPA 均不在云服 ZIP 内，不能将其内网连接地址当作云服地址。

需要回滚时停止服务并成套恢复程序与迁移前数据库，勿在新旧程序运行期间拼接数据库文件。部署后检查管理面板、登录/绑定、存档导出，以及从 1.4.103 返回标题下载至 1.4.104。真实玩家导入属于覆盖操作，不作为自动部署检查。

本次服务端和管理面板隔离构建通过，登录、旧存档迁移、继承兼容、管理界面、未备注清理、HTTP 存档传输、导出 Worker、存储兼容和 V2 快照九组回归通过。精确提交哈希、文件清单、包哈希、运行镜像同步及 CI 状态随最终交付回执提供。打包不等于已部署云服。
