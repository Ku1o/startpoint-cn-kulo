# 公网诊断包反馈流程

1. 安装最新公网诊断包，正常登录游戏。
2. 进入幻想、五重决战等场景，重复测试队伍编成、进入战斗、返回和再次进入。
3. 出现卡顿、长时间加载、F1063、闪退或其他异常后，不要先卸载或清除游戏数据。
4. 打开手机应用列表中的 **星点诊断日志**；也可以在游戏标题页点击 **诊断日志**。
5. 等待日志整理完成，点击 **分享日志文件**，选择 QQ、微信或其他发送应用，把生成的 ZIP 发给我们。无法直接分享时，可以先点 **保存到下载文件夹**。
6. 同时附上：发生时间、模式和操作路径、异常现象、设备型号及 Android 版本。日志不自动上传，也不包含账号密码或存档内容。

如果没有异常，直接回复“测试通过”即可。完整 ZIP 优先，**复制诊断摘要**只能作为无法发送文件时的补充。
