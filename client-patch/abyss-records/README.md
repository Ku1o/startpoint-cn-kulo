## 行为

- 保留个人最佳。在有限层“关卡详情”顶部增加“本期全服最快”，仅展示时间，不展示玩家身份。无成绩显示“本期暂无通关纪录”。无尽关原详情不变。
- 点击后请求 `/abyss-records/<questId>?res_ver=<本机资源版本>`，最多等待 1.8 秒再显示弹窗；失败仍打开原说明并显示“暂时无法获取”。成功结果缓存 10 秒，再次打开时刷新；弹窗打开期间不持续轮询。切换场景后的晚到请求不再打开旧弹窗。
- 服务端仅接纳有服务器开战记录（内存或数据库恢复）、匹配 play_id/关卡/当前塔版本的单人成功结算。缺失开战记录的 rebuilt 恢复结算保留原有个人结算行为，但不进入全服纪录。用时必须为正整数且不能超过开战至结算的墙钟时间加 5 秒容差。这是基础有效性检查，不等于完整战斗反作弊。
- 以 `(revision, quest_id)` 主键原子更新最小值，同分保留先前纪录。查询只查公共纪录表，不扫描玩家；本机 10,000 次读取约 82.5 毫秒，仅是本机微基准，不是云服压力测试。
