2026-09-12 用户反馈机兵齿轮、蒸汽核仍显示“没有获取方式”，并确认安卓已经重新下载资源。运行日志也记录了 `.106-1`、`.106-2` 下载，故不能归因于未更新。

## 根因与修正

此前 `.106` 索引的关卡和枚举正确，但验证漏了活动容器。原 `ItemHowToGetQuestSearcher` 从 `getAllEvents()` 加支线活动构造候选 ID；`getAvailableQuestLogic` 会先剔除不在其中的活动，之后才看关卡日期、可见性和选择条件。

常驻机兵活动 1001–1006 位于 `event_folder_events` 的文件夹 1，普通 `event_list` 只有六个旧限时机兵。12 种齿轮/蒸汽核的有效常驻来源全部被这个门禁过滤。幻想/深渊 700098、700099 位于文件夹 2，同样受影响。有效链复现见工作目录 `F:/codex/work/mech-navigation-regression-20260912/source-gate-audit.json`。

本修正只在普通活动匹配失败后补查真实文件夹成员：要求文件夹已解锁、活动处于开放期，然后继续执行原有全部关卡过滤及跳转。普通活动和支线活动的成功结果保持，未知活动、未解锁文件夹和未开放/过期活动不放行。不改 `event_list`，避免活动首页出现重复入口。
