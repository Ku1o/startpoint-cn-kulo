魂珠图标一键转换工具 1.1
==========================

使用方法
--------
1. 双击“魂珠图标一键转换工具.exe”。
2. 点击“选择 PNG”，或者把 PNG/文件夹拖入窗口。
3. 选图后可直接查看原图、实时魂珠结果，以及五星装备格/魂珠格效果。
4. 确认输出目录，点击“一键转换”。
5. 生成文件名为“原文件名_魂珠.png”。若同名文件已经存在，会自动使用 _2、_3 等后缀，不会覆盖。

游戏内预览
------------
- “原装备”使用客户端五星装备框；“魂珠结果”额外使用客户端魂珠内框。
- 20×20 图标按客户端规则以 6× 最近邻方式显示在 168×168 图标格中。
- 预览只在工具窗口内合成，不会改动或写入游戏目录。

输入规格
--------
- 仅支持 PNG。
- 图片必须为 20×20 像素。
- 支持透明或半透明像素，输出会逐像素保留 Alpha 值。

转换方式
--------
- 程序内置了从 365 对原游戏“装备图标/魂珠图标”拟合的坐标颜色模型。
- 转换是确定性的：同一张输入图每次得到相同像素结果。
- 保存的 PNG 只包含转换后的装备本体，不会把预览中的魂珠底座或边框写进文件。
- 模型在 78,908 个原游戏可见像素上的平均 RGB 绝对误差约为 0.142/255。

注意
----
- 这是本地未签名工具。Windows 第一次运行时可能显示安全提示，可选择“更多信息”后运行。
- 如果图标不是原游戏常见的装备绘制方式，颜色仍会转换，但视觉效果可能需要人工微调。
