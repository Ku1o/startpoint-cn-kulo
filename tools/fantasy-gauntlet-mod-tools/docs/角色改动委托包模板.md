# 角色改动委托包模板

把本文件复制为压缩包根目录的 `request.md`，填写后与真正需要修改的源素材一起提交。

不需要制作 atlas、AMF3、ATF、CDN 哈希、补丁包或各种尺寸的小图。没有改动的内容请明确写“复用”，
不要复制其他角色文件凑数。

## I. 推荐压缩包结构

```text

├─ request.md
├─ references/
├─ masters/
│  ├─ base.png
│  └─ awake.png
├─ cutin/                      # 可选
├─ pixelart/                   # 可选
│  ├─ normal/

├─ effect/                     # 可选
├─ voice/                      # 可选
```

也可以像泳装希尔媞案例一样，直接提交未经筛选的原始完整导出包。此时仍需填写本模板，尤其要说明目标
角色、哪些内容需要替换，以及主动技能场上特效是复用、重皮还是原创。
