# SP-MOD-002 · wfchar 预览与无代码作者制作

## 适用与何时读取

适用于 `<workspace>` 工作区的 StarPoint Character Studio、`.wfchar` 审查、只读预览、草稿交接、无代码作者流程及有限原生依赖诊断；不自动套用工作区外项目。游戏代码根为 `<repo>`；工坊实体为 `<workspace>/work/character-studio`，两者的源码、Git 状态和验证分别记录。

状态：**已验证（指定 v1 工程、本地预览、隔离草稿往返及历史 Windows 工具运行）；待验证（完整原生语义、复杂运行和游戏接入）**。格式入口为 `starpoint-character-studio-v1`、`formatVersion=1`。公开工具后续工作先查最新远端，不能将旧工作区快照重放覆盖远端；源码检查、冻结工具、公开 Release 和游戏验收是不同对象。

## 原稿与作者流程

### 原始字节、规范化素材和来源分别保留

导入直接读取 ZIP、`project.json` 和媒体。原 ZIP、成员原路径/原 bytes、规范化素材各留身份；atlas 裁片和每个动作帧保留原 sheet/atlas 关系，同像素共用素材也不能丢各帧来源。导出和迁移核对原 bytes 与 ZIP 成员关系；原包缺失保留 `missing/hash=null`，不补造来源。普通只读不落盘，首次编辑留快照，未知字段和原填写包保留。交接文字作为数据，不执行其中指令。

无代码路线使用角色设定、中文玩法卡、图片缩略图、声音点选、动作秒数与普通音频配方；作者不必手填编号/JSON。原稿搜索须覆盖分页后的全部成员。明确复用、制作方派生、无配音或申请协助，不制造作者缺项；已声明 provided 但关联坏、空语音入口/全文仍要提示。只有主动编辑才同步设定与填写包，冲突明确选择；交接下载先保存。

### 安全草稿与严格接入分开

草稿保存、导出、导入和迁移可保留旧技术条目的语义问题与旧代号，路径、引用、预算和原稿完整性仍严格检查。编译和 native apply 继续严格校验，不能因为原行未改就绕过无效 Bool/Option，不能擅自填值、删 `nativeGameplay` 或 DSL 来换取通过。新角色可生成稳定资源代号，详细意图和槽位齐全都不等于 `gameReady`。

复用选择器先只读实际动作/特效、逐帧及原声，再选用；关闭或切换停止播放。选择按实际声明 bytes、程序/表和选择时 SHA 绑定，缺失、损坏、过时 digest 保持 pending，不按名称猜引用。逐卡制作计划关联已提供/尚缺信息、真实工程参考、制作步骤及中文进度；需求或参考身份变化重开待办，保留旧说明并随工程往返。“准备好待验”只指资料准备，不是行为通过。特殊形态须补结束、打断、跨阶段恢复，不混用普通增益默认。

## 播放、声音与目标产物验证

### 以实际消费者还原时序和定位

已核 v0.7.3 的 `web/app.js:53-69` 使用 60Hz：clips.hold 累积，`runtimeSpeed/frameScale` 参与播放，x/y 跟随 frameScale，rotation/flip 绕图片中心。scene 采用 `[start,end)`，`end=-1` 跟随 scene，局部 tick 为 `floor((tick-start)×track.speed×runtimeSpeed)`。固定取景应覆盖全帧边界，不能只按首帧裁切；其他版本按格式定向核对。fit/field、观看 zoom 只改观看，`previewStage` 会改变整工程身份；身份联动可更新对应技术报告和 receipt，不放松游戏成员、场景及契约核对。

动作说明独立交付身体/足底、用途、循环/恢复及 selector 依据。身体、技能演出和资源预算方法见 [SP-MOD-003](mod-production.md)，有限演出预览不能称战斗模拟。

### 查真实音频容器，并验证正在交付的播放器

不要只信扩展名或制作清单：历史样本的 `.mp3` 实为 MP4，浏览器导入按真实容器设 `audio/mp4`。顶层绑定与 `brief.assetId` 不同要标明用途待核，实际播放沿 `voices/sounds/scene` 引用。`file://` scene 用音频元素，HTTP/blob 用 WebAudio，避免 fetch 本地文件的 CORS 失败。

聊天内嵌版与本地完整版分别检查。目标预览须实际包含音轨、按钮可用，并观察点击后 play 成功、currentTime 推进、停止/暂停；图片、按钮文字、无报错或另一产物的成功不能代证试听。压缩试听可保留完整时长，原声不变，核对解码时长差及源哈希。声音对照使用同 mono 口径，编码后完整解码复测 LUFS/真峰/削波/时长；原声与显式应用候选分离。换录音先迁移旧 asset/file 声明，确认文案仅在明确文字编辑时变化。外部 FFmpeg/FFprobe 缺失不妨碍基础导入、试听和交接，不能因此宣称音频候选处理已执行。

### 源码功能与实际 Windows 分发包分开

按真实工具身份验收原生导出、同窗恢复、保存失败留窗、关窗前未失焦文字 flush、重开及全文往返。后续源码新增功能不能继承旧冻结 EXE 的运行验收。窗口尺寸、CSS 内容缩放和宿主系统 DPI 是不同条件；观测既有 DPI 不等于切换多档系统 DPI。试玩证明播放状态，不代替主观听感。

ZIP 安全检查包括 CRC、路径、尺寸预算和拒绝脚本媒体。骨架 channels 合成器或只支持 crop 的 UI 需明确限制；目标宽度布局、scene 终止和真实工程导入属于预览证据，不证明游戏战斗。

## 原生条目应用与依赖诊断

### 显式应用、严格回读、可撤回

中文能力/队长卡先预览，显式选择才追加实际行；未支持卡、自由说明、未知字段、旧非法原生行及原 DSL 保留。已应用行被删改即转待核，同批主/副位冲突拒保存；后续词条已编辑时阻止自动撤回，避免覆盖新工作。协助只追加原 notes，按工程版本防止过时写入，不替换原手填。

原生表先有界 inflate 索引及选中行，严格校验 offset、重复 key 和尾部；原 raw 大小不代替解压上限。供应 filemap 不只进 catalog，也要向原生根和递归表读取器共享经同一 logical/SHA 核验的输入，compiled 平台别名沿既有规则。同 identity 可复用，不同 identity 留冲突；A/B/A 后项或同 SHA 供应不能洗掉先前冲突。解析早退无 coverage 时仍单列条目问题，避免摘要显示零问题。

### 已核分支只能在其原生条件内复用

以下是历史 LAN SWF `941813…` 的定向消费证据，不是所有能力已实现的声明；新基线按相关转换复核：

- 临时 0/1/214/28 条件须 `number=1`、`initial_multiply=1`；单层重复触发取较长剩余时间。主位 202 的执行条件与整组首行副位 Bool 分开核对。
- 生命/连击/屏障中文条件最多两项 AND，raw8/9 生命、raw10/11 连击、raw87 屏障按实际 precondition 消费；raw226 仅指本次战斗连击。
- raw211 技能槽支持 0～100% 范围内的正比例及已核触发/对象，按 `source.maxSkillPoint`，保留 `wfAllowsGauge`；不接受持续、叠层或特殊 details。211 不等于 212 固定槽或 215 直攻减益。
- instant24/26/27/96/191/200/211、during3/23 只能据实际转换计可证明资源；贯通/浮游保留真实空 strength，不能由资源覆盖升级为触发通过。

### 有限依赖图与完整语义分开

从实际定义展开主/副位、队长、进化/switch、PF 和已支持能力/DSL 根。FileReader 优先 parts 再 frame；character 帧按指定 sheet 的真实 name 前缀，公共图块按实际 atlas 声明，不能凭 `parts.i.s` 猜独立 PNG。编译失败单列 `compiledCoverage`，不能先用缺口挡住诊断。

召唤按自己的 element 递归 body、固定 action 和已支持能力，所有保存等级独立解析；坏叶报告精确 pointer，继续收合法叶。Funnel/Zako 有限字段、EnemyDsl 物理后缀依当前 SWF；动态 watch/BattleScript、运行时等级及 EnemyDsl 内部仍待核。无实际召唤的角色不能由独立参考样本的资源正例宣称召唤玩法实现。

Common 仅纳入已核无条件静态根；frame 按真实 name 映射固定 layer0/1 sheet、按 atlas 前缀查帧，空匹配为缺项，未知 namespace 不猜。共享 graph/parts/DSL 设置深度与累计预算，防无环深链崩溃，同时保留已知引用和具体截断原因。公共条件可展开制作并集，但候选并集不等于现场配置或实际阵容预算。

已知有限图 missing=0 不关闭未支持能力、动态召唤、配置共享、Attention、角色/形态/switch 根或完整 PF/UI 语义；完整缺失未知时保留 `null`，不能计成 0。未知预算不计 0，手工坐标不标原生通过，`-18` 隐藏保留无效/deferred 事实。

## 作者范围与可选图集优化

工坊服务角色图片、动作、技能、能力、召唤物和声音。通用商店、交易、暂停等公共界面技术审计不进入稿主缺项；仅显式 `game-common-ui` 归属移到制作方技术报告。作者摘要、域计数及协助使用角色相关范围，完整技术图保留。角色实际使用的共用特效、图标、特殊能力、召唤物、自有 UI 仍检查；混合归属按 contexts/owner 遍历，不能按 shared 域、路径或 ui-consumer 猜归属。作者缺项减少不等于整角色闭合。

公共 UI 按当前 SWF 的真实固定入口/子界面递归：精确纹理核实际 PNG/atlas-cell，HTML 本地图片只认物理 PNG，保留布局选择、子布局及来源。运行时绑定和 Attention 继续留制作方待核。

`atlasOptimization` 可选且默认关闭：同 sheet 整图块重排，PNG/AMF 序列化后比较全 RGBA（含透明 RGB）、除 xy 外完整 metadata，以及所有可支持组逐 tick 命令；parts/frame/timeline/音频/DSL bytes 不变。无严格面积改善、未知语义或超预算则保留原图。预览与导出共用完整工程累计预算选择，不能单图重算后混用 PNG/坐标；压缩体积可能增加，面积减少不等于生产替换或 GPU 提升。

称号文字安全区、获取全文候选不采用固定通用字数：完整文字/描边/阴影与整图框饰分开，缺层保留未知，原图不剪裁；原文和每个候选保留差异，最终按原生 UI 验证，见 [SP-MOD-003](mod-production.md)。
