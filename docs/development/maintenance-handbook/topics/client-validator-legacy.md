# SP-CLIENT-001 · LAN 校验器摘要缺字段的历史绕行

适用：Android LAN 基线核验。仅当出现精确错误 `ERROR: 'method_bodies_checked'`，或旧记录建议跳过校验器时读取。状态：**已过时**（历史缺字段前提在当时定向复核中已消失）；不是通用 APK 故障处理方式。

## 原因与退出条件

旧 LAN 登记的 `local_build_checks` 缺少摘要字段，校验器在构造返回摘要时直接读取它。当时独立 APK/SWF 哈希、大小和 AIR UUID 匹配，所以该摘要异常不能解释为包身份失败。2026-10-09 静态复核时 public/lan 均已有对应字段，只证明原缺字段前提消失，未重跑完整验包。

默认使用当前[Android 登记](../../../../client-patch/android-accepted.json)与[现有校验器](../../../../client-patch/verify_android_baseline.py)。字段与 schema 已相容时，不再执行历史绕行；本专题不固定维护当前字段值或方法数量。

## 若同类错误再次出现

先定位当前失败阶段、实际登记与 schema。只读范围内可对同一身份声明做等价独立检查，保留完整失败信息、已覆盖内容与未覆盖限制；缺文件、哈希不匹配等真实身份失败不得用旧摘要错误掩盖。若确认是 schema 兼容缺陷，根本修复属于校验器/登记契约及相应回归，按该代码范围授权处理，不把一次绕行变成永久豁免。

代表证据：历史救援铃铛交接（历史本地记录）。完整旧记录见历史原文（历史本地记录）。本次只整理现有证据，未重新核验登记字段或客户端包。
