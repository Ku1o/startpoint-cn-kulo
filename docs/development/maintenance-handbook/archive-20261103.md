## 恢复入口

1. 先取得本仓库 main 的源码与本文目录中的方法手册。制作工具在 `tools/production-kit/`，AIR 方法执行和后台辅助工具分别在 `tools/client-air-test/`、`tools/client-background/`。语音环境的来源、版本及重装清单在 `tools/voice-reproduction/`。
2. 按需下载附件，先核对整个 ZIP 的 SHA-256，再检查包内 `ARCHIVE-FILES.json.gz`。该清单记录成员路径、归档字节哈希与原始输入哈希；部分说明和元数据经过隐私整理，因此两者可能不同。
3. 解压到独立工作目录。附件的 `workspace/` 保存原工作区相对布局；不要覆盖正在使用的仓库、数据库或当前成品。历史脚本仍可能包含绝对路径，恢复后应调整输入、工具、仓库和输出目录。
4. 卡池模板已用可移植制作工具重放，结果为 5 页、21 个资源且逐项字节核对一致。其他历史角色/客户端附件经过身份、格式及静态检查，没有宣称每个旧脚本都可在任意机器直接运行。
5. 当前客户端身份继续以 `client-patch/android-accepted.json`、`client-patch/ios-accepted.json` 为准。归档时公网 Android/iOS 为 accepted_offline；独立内网包沿用自己的已登记版本。IPA 未签名；本归档不包含签名凭据。
