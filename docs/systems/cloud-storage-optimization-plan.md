## 一键与持久化

收到完整引导文件和更新 ZIP 后，双击 `maintain-cn.bat`。工具处理云服当时的数据库，完成程序/数据备份、必要升级、校验、空间整理和生产服务重启，不导入本机拷贝。无需管理面板按钮。

ZIP 由工具先暂存校验，再逐文件备份、原子替换，不应先手工覆盖解压。实际数据、规则、迁移版本和任务状态跨重启保留。中断通过 `maintain-cn-recover.bat` 恢复；一旦进入重新开放服务的阶段，不自动覆盖回旧数据库。
