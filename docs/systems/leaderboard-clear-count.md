# 排行榜通关次数

排行榜按竞赛和赛季统计每位玩家的有效完整通关次数。每次从第一战开始、
完成全部战斗、具备全部逐战记录且总战斗用时大于零的记录计为一次；
较慢的重复通关也累加。失败、放弃、中途开始和缺失逐战记录的通关不计入。
次数不参与排名或发奖，仍按每位玩家的最佳总战斗用时排序。

游戏内复用原 `BEST RECORD` 的 `count` 文字区域，显示 `通关次数：N次`，
最佳用时仍显示在 `time` 区域；列表和“我的排名”使用相同口径，未入榜显示零次。
现有服务端驱动排行榜客户端可直接显示，无需改动 APK/SWF。
管理页新增“通关次数”列，管理接口返回 `clearCount`，官方格式接口返回 `clear_count`。

当前赛季从已有 `leaderboard_runs` 记录实时汇总，因此完整历史记录会直接计入。
换季后重新统计；关闭榜单时回看的上一赛季仍显示该期次数。
新结算把次数保存到 `leaderboard_settlement_results.clear_count`，之后删除玩家或
清理通关记录不会改变已保存的次数。旧库启动时自动添加该可空字段，不改数据库版本号。
旧结算没有计数快照时，从仍保留的本期记录中计算截止结算时的有效通关次数；
若这些历史记录已被删除，则显示“未记录”，不推测次数。排行榜上线前没有保存的
通关记录无法补算。

验证：先执行 `npm run build`，再用 Node 测试运行器执行 `tests/leaderboard-*.test.js`
回归集（Windows PowerShell 需先展开文件列表）；管理页在 `admin` 目录执行 `npm run build`。
