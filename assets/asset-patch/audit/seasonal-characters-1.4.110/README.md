## 慢通关与 EX 配套

三张铭牌为艰难依然前行（9911101）、蠕动化区（9911102）、肉鸽爱好者（9911103）。同一次完整 30 关的各关战斗时间之和严格大于 60 / 120 / 180 分钟时领取，奖励可累计；等于阈值不领取，不含关外等待。失败、重开、重复结算、缺关和跨塔版本不会拼成有效完整通关。排行榜关闭不阻止成就计时。此前未完整追踪的历史对局不追溯补发。

普通深渊当前绑定 700099 / folder 1。EX 后续接入需完成：

1. 在 assets/abyss_endurance_degree_reward.json 的 ex 项填入实际 event_id 和 folder_id，保留 normal 项。
2. 为真实 EX 塔发布有效 quest_time_revisions["rush:EX_ID"]；没有此标记时成就追踪不会启用。
3. 沿用 Rush 开始、结算和重置入口，提供 1–30 关身份及每关实际战斗毫秒。src/lib/leaderboard/service.ts 与 src/routes/api/singleBattleQuest.ts 已接入通用钩子。
4. 将 assets/abyss_ex_campus_season_template.json 的铭牌档位绑定到真实 EX 新赛季奖励配置。该文件目前只是模板，不会自动发奖；event_id、season、enabled 及其他奖励应随 EX 任务确定。

慢通关使用 achievement:abyss-endurance:事件:文件夹 的独立运行记录，不与排行榜赛季混用；普通和 EX 任一种完整通关都可满足同一组称号条件，不能跨模式累计单次 30 关。

## 存档与构建

新角色和铭牌沿用既有数据库结构。V1 导出增加可选 degreeList，携带铭牌 ID 和领取时间；旧 V1 缺该字段时保留目标已有铭牌，新 V1 可迁移铭牌，V2 结构和指纹不变。非法铭牌数据在写入前拒绝；账号身份与服务器本地运行记录保留。

构建配置限定 src/**/*.ts，避免历史输出目录的源码副本被纳入编译；三个 worker 错误处理点兼容 unknown 类型。npm run build 通过，构建进程临时使用 12 GB Node 堆上限。
