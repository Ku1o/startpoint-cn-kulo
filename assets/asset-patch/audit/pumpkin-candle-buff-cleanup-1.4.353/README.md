# 地狱南瓜蜡烛加攻清理 1.4.353

追加 1.4.352 → 1.4.353 数据边，保留 1.4.352 原包及其五重减难、南瓜爆炸和清场逻辑。
七个 common 动作资源同时用于 Android/iOS：六份蜡烛加攻程序和共用死亡程序。

蜡烛施加的是可驱散加攻，但旧死亡程序的 `DeleteCondition` 第四参数为 1，
只选不可驱散状态，不能匹配该加攻。现在将此参数设为 0，并在两端使用
`mod_hp_candle_attack` 专用标识，死亡时仅撤掉一份蜡烛加攻，不误删 Boss 其他攻击增益。
六种蜡烛加攻值相同，共用标识只限定撤销范围；不改变状态来源、叠加上限或单次移除数量。

声明的动作参数变化仅为：`CreateCondition` p7；`DeleteCondition` p4、p5。
目标、25% 加攻、持续时间、移除数量、演出和其他动作参数保持不变。
无玩家保存 ID、奖励来源、数据库、APK/IPA 或准入变化。
