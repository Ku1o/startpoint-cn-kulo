# 1043 角色内容内网候选

资源版本从 1.4.116 追加至 1.4.117，旧分包保持原字节。新增分包包含 2,071 个成员：35 项表数据变更所在的完整表、对应媒体、15 个旧 MOD 角色的客户端兑换标志及稻穗两形态技能修复。

作者资源按 1033 到 1043 的实际差异整合：1,074 个媒体变更，补齐 972 张原生 0.7 比例小图和 14 份独立编码的 iOS 纹理。27 个作者铭牌继续使用已有本服映射，整个铭牌表不变。服务端同步杰拉尔和芙拉菲文本，并只开放普通深渊池的 15 个指定旧 MOD 角色兑换。抽取权重、990002 池和 12 个新角色的零权重、兑换限制保持原状。

稻穗两形态技能各修正四处敌方状态清除为 `DCAll(2)`、一处队友清除为 `DCAll(3)`；保留次数、范围及其他技能节点。原始错误资源和注入的错误枚举均被验证器拒绝。生成源的两个对应常量也已修正，未重新生成无关动作。

客户端从已登记的 Android SET C8601 基线继续构建，补齐 423/424、回槽来源和伤害分类机制，以及三组待机语音的播放与预加载入口。静态机制与语音检查共 37 项通过；服务端的五项测试包含真实兑换路由、积分扣除、奖励发放和拒绝边界，使用独立临时数据库。

现有 8001 服务返回 1.4.117，实际下载 ZIP 与源分包 SHA-256 一致，当前版本不重复触发下载。APK 通过持久证书、v1/v2 签名、对齐、AIR UUID 和原准入配对检查。

本次不增加存档 ID、数据库结构或导入导出格式。数据库验证没有使用真实玩家账号。资源及客户端均为内网候选，战斗手感、画面和音频主观效果待设备测试；iOS IPA 待后续构建。尚未正式发布或部署云服。
