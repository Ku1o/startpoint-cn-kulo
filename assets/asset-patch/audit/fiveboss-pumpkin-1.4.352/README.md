# 五重减难与地狱南瓜 1.4.352

在 1.4.351 上追加一条数据边，内容来自测试服 1.4.344、1.4.346、1.4.348、1.4.349、1.4.350。
测试服这些版本号与本链同号不同内容，本边不复用测试服的包，而是以本链 1.4.351 的有效视图为底重新构建。

## 改动

五重（`boss_battle_quest` 分组 99 共 39 关，`general_boss` 34 个键 64 行，5 个 DSL，新增 `fb3_buff$entrance_self`）：

- 防御 up 从 12 层改为 5 层，删除不可驱散的 `fb3_half`。伤害倍率按驱散次数为 1% → 21% → 41% → 61% → 81% → 100%。
- 登场减益从 4 个减为攻击、防御 2 个，并去掉强制付与；`silence_waves`、`sig_king_seal` 的沉默去掉强制付与。
- 狂暴删除耐性叠层；`enrage_r0` 改为只给自己叠，每只 boss 1 份，最多 8 层。攻击叠层可驱散。
- 同波非首位 boss 只保留自身增益，玩家减益和场地词缀只由首位 boss 施放。
- 39 关 boss 血量 `c99` ×0.35，杂兵 `c97`、召唤物 `c98` 不动。

地狱南瓜 P3（`funnel_level` 12 行，`general_boss` 的 `mod_hp_rage`、`mod_hp_rage_multi`，`general_boss_state`，`hp_rage_marker`，9 个 DSL，新增 `hp_boom_candle`）：

- 烛心 `hit` 300 → 6000，地狱档约 1566 万 → 3.13 亿一只。
- 烛心入场 60 帧无敌。
- 每只存活烛心给 boss 的加攻 +50% → +25%。
- 大爆炸从普通伤害 3 段 ×2.0 改为全队最大 HP 50% 一段，每只存活烛心再加一段最大 HP 40%。
