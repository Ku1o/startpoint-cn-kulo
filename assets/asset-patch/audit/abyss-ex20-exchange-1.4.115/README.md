# 深渊 EX 三兄弟与角色兑换修复

## 行为

EX 第20关原先使用 `shark_score_event`。它生成的蓝、棕实体没有 damage_share 目标，本体却等待50%血量切换阶段；红色逃跑演出不是可攻击的最终阶段。因此辅助实体可以倒下再恢复，本体血量不会随其受击下降。

本修复保留三兄弟，建立普通讨伐版的21个私有实体和68份动作脚本，将生成、传伤、状态和伙伴监听完整映射到私有代号。三个主要实体的传伤目标均为 `mod_ex20_shark`。普通讨伐使用的原生地形与第20关一致，无迁移到异地地图。源版普通及计分活动资源保留原字节。

本体沿用第20关的 boss_level，约298.28亿血量，保留属性、伤害、领域、奖励及时限设置。辅助实体HP按相同比例缩放，九处 GeneralFunnel DamageCheck 只反向调整c16百分比，绝对破弱点伤害及其余状态参数不变。原生阶段动作的21个实体名及动作路径之外不作替换；反向映射可完整恢复原生动作树。

盾牌座149988与夏日白149990在深渊池990001可使用250点兑换。两份服务器配置各只修改两个 isExchangeable 标志，客户端同步对应两行与说明。抽取权重各1000不变，可兑换角色由50增至52；竞速池990002保持原配置。角色兑换入口由卡池资格表驱动，无新增物品或物品商店来源。

## 验证及边界

- 隔离数据库通过真实兑换接口验证249点拒绝且不扣点、250点成功扣除并拥有角色，以及其他禁止兑换角色保持禁止。
- 公共服务器 accessor 验证两名角色最终生效资格，避免基础配置被 cnmod 覆盖。
- 新资源逐一序列化回读，ZIP逐项比较，68份完整ActionDSL签名检查与反向重放通过；21个原生实体、原有监听和其他关卡均保留。
- 状态、传伤、地形与动作闭包检查通过，九处破弱点绝对阈值保持一致；这属于离线检查，不代表手机战斗已经通过。
- 抽池、克隆与HP锚门禁拒绝计分版鲨鱼再次进入击杀通关塔。CreateCondition第8参数按客户端可空 linkedHitCheckKind 契约校验，其他枚举位置仍严格校验。
- 资源版本1.4.115，只推进EX计时成绩版本，普通塔成绩及挑战进度保留；未设置 rush_tower_resets。无存档结构、角色ID、账号归属、奖励或领取记录变动。已有V1/V2存档无需迁移。

## 交付范围

运行需要两份 gacha JSON、完整 manifest 及新的 active ZIP。无需重新构建APK/IPA。部署后两端须下载到1.4.115，服务端须重新加载卡池配置。提交、运行文件同步及私有云服包交付状态见批次回执；未部署云服，未进行手机实战或覆盖安装。

`report.json` 记录源文件摘要、81个客户端资源、九处阈值及EX版本标识。构建脚本为 `tools/fantasy-gauntlet-mod-tools/repair_abyss_ex20_exchange_115.py`，锁定输入1.4.114，不覆写既有发布ZIP。
