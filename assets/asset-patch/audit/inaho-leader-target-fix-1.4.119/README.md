# 中秋稻穗详情 C7050 修复（1.4.119）

## 修复范围

- `leader_ability.orderedmap` 的 `159991`，从零计数的行 15、列 46：空字符串改为 `0`（Myself）。仅此一个单元格变化；目标明确为自身。
- 保留连击条件、倍率、冷却、其他队长技、全部普通能力、主动技能、PF、语音、特效、显示文本与芙拉菲修复。
- 修复原生成器，并增加必填目标检查。已发布 1.4.118 ZIP 保持原字节；修复通过独立 1.4.118 → 1.4.119 边送达。
- 不改 APK、IPA、准入配置、保存 ID、数据库或导入导出格式。

- 实际内网 APK 的 SWF 解析字节码在旧数据上复现 C7050；修正后的已序列化分包解析为自身 SkillGauge，强度 1500（1.5%）。
